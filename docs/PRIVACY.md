# Политика конфиденциальности «Эфира»

> Шаблон для владельца сервиса: перед запуском для посторонних людей впишите контакт оператора и проверьте текст у юриста.
> Описывает то, что делает код на момент написания; при изменении кода документ нужно обновлять.

## Кратко

- Аккаунтов, телефонов и почты нет. Вы идентифицируетесь случайным id и ключами, созданными на вашем устройстве.
- Переписка хранится **на ваших устройствах**. Сообщения шифруются на устройстве (ECDH + AES-GCM, Double Ratchet) до отправки.
- Сервер сигнализации — посредник: он соединяет устройства и временно держит **зашифрованные** сообщения для тех, кто не в сети. Прочитать их он не может.
- Реклама, аналитика и трекеры не используются.

## Что где хранится

| Где | Что | Как удалить |
|---|---|---|
| Ваше устройство (localStorage, IndexedDB, Cache Storage) | профиль, контакты, переписка, файлы и голосовые, ключи, настройки, черновики, кэш приложения | Настройки / Отладка: «Полное удаление»; очистка данных сайта в браузере; удаление PWA |
| Устройства собеседников | копия сообщений, которые вы им отправили | вы не можете удалить их копию |
| Сервер сигнализации (оперативная память и, если включено, диск `DATA_DIR`) | см. ниже | сообщения уходят сами по сроку; id-claim и push-подписку можно сбросить полным удалением |
| Сторонние хосты (см. ниже) | модель распознавания речи, wasm, превью ссылок, TURN | зависит от провайдера |

Пароль-PIN (если включён) шифрует переписку и ключи на диске устройства. Забытый PIN = данные не восстановить. Это защита «в покое»; от вредоносного кода на открытой странице она не спасает.

## Что видит сервер

- **Не видит:** тексты, файлы, голосовые, имена в чатах, содержимое групп — всё это только шифртекст.
- **Видит и обрабатывает:** хэш вашего id, публичный ключ, публичные prekeys, отображаемое имя (если вы его разрешили передавать), факт подключения (онлайн/офлайн), IP-адрес соединения (для лимитов и маршрутизации), размер и время пересылаемых пакетов, кому адресован пакет (id получателя), тип пакета.
- **Claim-токен id:** сервер хранит только sha256 от производного значения, чтобы чужой не занял ваш id. Освобождается через 14 суток неактивности.
- **Ящик (офлайн-доставка):** шифртекст для вас хранится, пока вы не заберёте его. Максимум — текст 14 суток, файлы и голосовые 48 часов, затем удаляется. На бесплатном Render без Persistent Disk ящик пропадает и при перезапуске сервера.
- **Push:** если вы разрешили уведомления, сервер хранит адрес push-подписки вашего браузера (endpoint и ключи подписки). Уведомление не содержит текста сообщения; сервис доставки (Apple, Google, Mozilla) видит факт и время отправки уведомления на ваше устройство.
- **Журналы:** сервер печатает технические события без содержимого (сокращённые id). Срок хранения журналов определяет хостинг (Render).

## Сторонние сервисы

- **GitHub Pages** отдаёт файлы приложения и видит обычные веб-запросы (IP, User-Agent).
- **Render** (или ваш хостинг) запускает сервер сигнализации.
- **TURN-серверы** (coturn / Cloudflare / другие, если настроены) ретранслируют уже зашифрованный WebRTC-трафик, когда прямое соединение невозможно, и видят IP и объём.
- **Превью ссылок:** если включено, адрес ссылки запрашивается через сервер, который скачивает страницу (og-теги). Сервер видит адрес ссылки, но не контекст чата.
- **Перевод сообщений:** по умолчанию использует внешний сервис перевода (LibreTranslate), которому уходит переводимый текст. Включается вами; можно указать свой адрес.
- **Локальный ИИ (расшифровка голосовых):** включается только после согласия. Скрипт библиотеки лежит на нашем origin; из сети скачиваются **модель Whisper (≈40–80 МБ) с huggingface.co** и wasm-файлы onnxruntime с cdn.jsdelivr.net. Эти хосты видят ваш IP и факт загрузки. Само аудио никуда не отправляется — распознавание идёт на устройстве. Модель можно удалить в настройках.
- **Шрифты** лежат на нашем origin, внешние шрифтовые сервисы не используются.

## Отчёты об ошибках и проверка устройства

Кнопки «Сообщить об ошибке» и «Проверка устройства» (вкладка «Отладка») ничего не отправляют сами. Они собирают текст (версия, тип устройства, технический журнал, результаты проверок), очищают его от текстов сообщений, имён, ключей, токенов и адресов с параметрами, и показывают вам. Отправлять ли его — решаете вы.

## Ваши права и удаление данных

1. На устройстве: Настройки → «Полное удаление» (или «Отладка → Полный сброс»). Удаляются ключи, переписка, файлы, кэш.
2. На сервере: после полного удаления ваш id перестаёт использоваться; ящик очищается по сроку (не более 14 суток), push-подписка отзывается при отключении уведомлений. Для немедленного удаления данных на сервере напишите оператору (контакт: ______).
3. Резервные копии, сохранённые вами в файлы, удаляются вами вручную.
