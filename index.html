Translation server

Empty by default — translating a message sends its text in the open to this server, so pick one you trust. Without one set, "Translate" in a message's menu just explains that.

Backup

Ether has no server backup — everything lives only on this device. If you lose or replace this device, contacts, groups and messages are gone unless you save a backup file yourself.

Danger zone

Best-effort, not a guaranteed silent trigger — a sharp shake (e.g. someone grabbing your phone) shows a brief cancellable warning, then wipes this device if not cancelled. False positives are possible; test it before relying on it.

Host your own server

Ether's signaling server never sees message content — only who's online and brief routing metadata (and, for file previews, a fetched link). Running your own gives full control over that metadata, useful for firms, clinics or teams that need "the vendor can't see our traffic" in writing.

cd signaling-server && cp .env.example .env && docker compose up -d

1) Edit .env with your VAPID keys (npm run generate-vapid) and domain. 2) Deploy behind HTTPS/WSS (a reverse proxy like Caddy or nginx works well). 3) Paste your wss:// URL into "Signaling server" above.

Full steps, env variables and a sample compose file are in signaling-server/SELF_HOSTING.md in the Ether repository.
