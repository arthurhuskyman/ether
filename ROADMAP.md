# Дорожная карта «Эфира»

Источник: внешний обзор зрелости приложения (октябрь 2026, V.62.0.7). Здесь собрано всё, что из него **не сделано**, чтобы вернуться позже. Идентификаторы (B…, D…, A…, C…, F…, U…, У…) — из того обзора. Перед работой над пунктом проверяйте его по коду: часть замечаний обзора оказалась неточной (см. «Уже закрыто»).

## Уже закрыто
- Исправлены (V.63.0.0): B1 (черновик из режима правки), B2 («прочитано» для файла при прокрутке вверх), B3 (подсказка при дебаунсе звонка), B5 (явная инициализация блокировки PIN), B7 (параллельная TURN-проверка), B11 (ожидание pong при возврате из фона 3→5 с), B12 (лимит размера исходного файла аватара 25 МБ).

## Дизайн-обзор №2 (V.65.0.0)
Сделано в V.68.0.0: голосовые комнаты (флаг у группы, плашка «Внутри: …», вход без звонка и мелодии, пульс присутствия 20 с, до 6 человек — это mesh, не SFU; присутствие видно только по P2P) и локальный ИИ (расшифровка голосовых Whisper-tiny через transformers.js после явного согласия, краткое содержание — частотная выжимка без нейросети). Сделано в V.67.0.0: русские плюралы (`key.one/few/many/other` в словаре, подбор по `Intl.PluralRules`) и неразрывные пробелы; плавная смена темы; контраст разделителей OLED; обои (5 готовых + свой градиент); голосовые стопкой; опросы: открытые, с автозакрытием; переименование колонок доски; совместные списки; треды (плашка «N ответов» и лист ветки); «оба печатают»; тихие часы; текстовые истории на 24 часа; пустые состояния с действиями (поиск, звонки, контакты); пояснения под сложными настройками; область нажатия ≥ 44 pt у новых и мелких кнопок.

Сделано в V.66.0.0: единый набор иконок `js/icons.js` (меню, шапки, композер, вкладки, строки настроек, шторки), голосовые (волна из метаданных, перемотка по волне, скорость 1×/1.5×/2×, пауза записи), опросы и доски (канбан) в личных чатах и группах, демо-чат в онбординге, анимации галочек и копирования.
Сделано в V.65.0.0: токены (`css/tokens.css`), шкалы типографики/радиусов/движения, иерархия списка чатов, меню «+», панель реакций и шторка сообщения по уровням, пресеты Calm/Default/Playful, карточка первого запуска, многострочный ввод, пакет доступности, окно отрисовки длинных чатов, `content-visibility` у строк списка.

Опросы/доски: нет анонимных опросов, ограничений по времени и совместного редактирования названий колонок; операции над доской сходятся по времени автора операции (расхождение часов устройств возможно, поправка до +1 мин).

## Дальше по Double Ratchet (доводка C1)
- Подпись сообщений и prekey долговременным ключом подписи (C2): сейчас подлинность держится на ключах личности и их подтверждении.
- Сверка числа безопасности по QR/руне при подтверждении нового ключа (сейчас — цифры вручную).
- Индикатор в чате: «канал подтверждён / без подтверждения» (состояние `link.authState` уже есть, в интерфейсе не показано).
- Показ состояния сессий Ratchet во вкладке «Отладка» (сейчас `Ratchet.info(id)` есть только для тестов).
- Групповые сообщения: sender keys вместо отдельной шифрации на каждого участника (A1).
- Для P2P-сообщений отдельный Ratchet сверх DTLS не делался: после проверки подлинности DTLS даёт конфиденциальность и forward secrecy канала; дополнительный слой имеет смысл, только если понадобится защита от компрометации конечной точки или хранение зашифрованной истории.

## Архитектурные риски
- **A3.** `id = SHA-256(телефон|почта)` без соли — перебор номеров занимает минуты. Нужен соль/медленный хэш (миграция id затронет всех).
- **A4.** Ящик сервера в памяти: после перезапуска Render недоставленное теряется. Нужен постоянный ящик (Redis/диск) с TTL.
- **A5.** `group-invite` не проверяет, что отправитель — админ; любой участник может переписать состав/название/аватар.
- **A6.** Web Push на iOS ненадёжен; нативная обёртка (см. A4 ниже).
- **A7.** `iceCandidatePoolSize: 2` на каждый PeerLink при сотне контактов даёт десятки allocation на TURN; ограничить пул/создавать по требованию.
- **A8.** Превью ссылок загружает сервер с чужого IP: сделать opt-in на каждое сообщение.

## Криптография и приватность
- **C2.** Подпись каждого сообщения (Ed25519/ECDSA), предупреждение при смене ключа.
- **C3.** Multi-device: корневой ключ личности, устройства подписываются им, зашифрованная синхронизация.
- **C4.** Постквантовый гибрид (X25519 + Kyber768).
- **C5.** Шифрование хранилища на устройстве ключом из PIN (Argon2id), файлы — отдельными ключами.
- **C6.** Sealed Sender: сервер не знает отправителя.
- **C7.** Проверка личности без цифр: QR/руна уже есть; добавить пуш при смене ключа и режим «требовать верификацию перед звонком».

## Сеть и масштаб
- **A1 (сеть).** Группы: замена mesh на sender keys (до сотен участников).
- **A2 (сеть).** SFU для групповых звонков (6 → 32+).
- **A3 (сеть).** Постоянный ящик на сервере.
- **A4 (сеть).** Нативные обёртки iOS/Android для фоновых задач и пушей.
- **A5 (сеть).** Федерация серверов (Matrix/Nostr-подобная модель).
- Звонки на LTE у «Мегафон/МТС/…»: свой TURN на российском VPS (`deploy/setup-coturn.sh`), запасной голосовой канал через сервер, подсказка «включите VPN/Wi-Fi».

## Функционал
- **F1.** Исчезающие сообщения отсчитывать от прочтения, не от отправки.
- **F2.** Правка/удаление/реакции в группах (частично уже есть, проверить полноту).
- **F3.** Настоящие треды вместо «мини-тредов реакций».
- **F4.** Совместное редактирование заметок/списков в чате.
- **F5.** Локальный ИИ (транскрипция голосовых Whisper-tiny, краткое содержание) в WebAssembly.
- **F6.** Голосовая почта.
- **F7.** Видео 1:1 с simulcast.
- **F8.** Локальные «истории» с E2E и истечением.
- **F9.** Постоянные голосовые комнаты.
- **F10.** Синхронизация черновиков между устройствами (после multi-device).

## Дизайн и UX
- **U1.** Единая дизайн-система: токены в `tokens.css`, стили по компонентам, `data-variant` вместо дублирования правил.
- **U2.** Плавная смена темы (transition 200–300 мс).
- **U3.** Иерархия в списке чатов: главное (имя, превью, время, бейдж), второстепенные иконки убрать под свайп.
- **U4.** Обучающие пустые состояния (три способа добавить контакт).
- **U5.** Интерактивный онбординг (демо-чат с самим собой).
- **U6.** Единая система движения (длительности, easing, правила).
- **U7.** Настройки: группировка с заголовками и пояснениями под сложными переключателями.
- **U8.** Единый набор иконок (Lucide/Phosphor).
- **U9.** Типографическая шкала (заголовок 17–22, тело 15–16, мета 12–13).
- **U10.** Доступность: проверка VoiceOver/TalkBack, Dynamic Type, `prefers-reduced-motion` везде, тап-таргеты не менее 44 pt.
- **U11.** Больше оптимистичного отклика на действия (отправка сообщения и т.п.).
- **U12.** Контраст разделителей в OLED-теме.
- **U13.** Свои обои чата (градиент/паттерн).
- **U14.** Дорожка голосового с быстрой перемоткой, как в Telegram.
- **U15.** «Оба онлайн, оба печатают» и подобные взаимные индикаторы.
