## Сделано в V.87.0.0 (долги по документу, `js/app/22-wave87.js`, `signaling-server/{sfu,blobs}.js`)

- SFU для групповых звонков (`signaling-server/sfu.js`, werift): одно соединение с сервером вместо сетки; сервер пересылает RTP не декодируя, поэтому кадры, зашифрованные на устройствах (V.86), для него непрозрачны. Только участники группы из реестра, до 25 человек. Клиент: режим «Групповые звонки через сервер» (авто для групп больше 6, всегда, никогда), без шифрования кадров на устройстве через сервер не звоним; отказ сервера — продолжение сеткой. VPS: `SFU=1`, UDP 40000–40100, внешний адрес определяется при установке.
- Большие файлы в группы (до 16 МБ) одним блобом: шифруется один раз случайным ключом, шифртекст — в `signaling-server/blobs.js` (одноразовый билет, квота в сутки, срок 7 дней), участникам — ссылка с ключом. Скачивание только со своих серверов.
- Запечатанный отправитель: конверт дополнительно запечатан на ключ получателя и уходит с анонимного соединения; сервер не видит, кто отправил. Пускает только с ключом доступа получателя (известен его контактам). При отказе — обычная доставка. Выключается в «Приватности».
- Мелодии звонка, не попавшие в предзагрузку, кэшируются при первом прослушивании и играют без сети.
- Перевод 141 новой строки V.84–V.87 на 70 языков (машинный, NLLB-200 локально; 97% строк, остальные — английский там, где перевод исказил числа или плейсхолдеры).
- Тесты: `signaling-server/test-blobs-sfu.js`, `signaling-server/test-sealed.js`, `tests/v87-wave.test.js`.
- Осталось (не код): адреса зеркал в `config.js` (нужны реальные домены), проверка скринридерами на телефонах, вычитка машинных переводов носителями.

Опросы/доски: нет анонимных опросов, ограничений по времени и совместного редактирования названий колонок; операции над доской сходятся по времени автора операции (расхождение часов устройств возможно, поправка до +1 мин).

## Дальше по Double Ratchet (доводка C1)
- Подпись сообщений и prekey долговременным ключом подписи (C2): сейчас подлинность держится на ключах личности и их подтверждении.
- Сверка числа безопасности по QR/руне при подтверждении нового ключа (сейчас — цифры вручную).
- Индикатор в чате: «канал подтверждён / без подтверждения» (состояние `link.authState` уже есть, в интерфейсе не показано).
- Показ состояния сессий Ratchet во вкладке «Отладка» (сейчас `Ratchet.info(id)` есть только для тестов).
- Групповые сообщения: sender keys вместо отдельной шифрации на каждого участника (A1).
- Для P2P-сообщений отдельный Ratchet сверх DTLS не делался: после проверки подлинности DTLS даёт конфиденциальность и forward secrecy канала; дополнительный слой имеет смысл, только если понадобится защита от компрометации конечной точки или хранение зашифрованной истории.

## Баги и несоответствия (не сделаны)
- **B6.** Заблокированному контакту при входящем offer не отправляется «busy», он продолжает ретраи. Решение продуктовое (ответ раскрывает блокировку) — обсудить.
- **B8.** `_tuneSenders()` при каждом `stable`, `enableVideo`, `switchCamera` обходит всех сендеров; мелкая оптимизация.
- **B9.** `setCallPhaseActive` не обновляет таймер в мини-плашке — задержка до секунды. Не проверено по коду.
- **B10.** `seenDeliverIds` — окно на 500 id; при плотном потоке сжимается. Рассмотреть хранение по времени.
- **B13.** Нет проверки `EtherFileLimits.isValidFileMetaSize` на отправителе до base64-кодирования файла для группы.
- **B14.** `wireSettingsScreen` не идемпотентен (защищён только `__appStarted`).
- **B15.** В «Хранилище» нет разбивки квоты по категориям (файлы, кэш SW, прочее).
- **D1.** Текст справки внутри приложения говорит, что файлы доставляются только онлайн, хотя файл до 2 МБ идёт и офлайн; править во всех языках.
- Словари: в 70 языках нет части новых ключей (`status.replaced`, `toast.noOtherOutput`, `toast.contactKeyChanged`, `call.tooSoon`, `toast.keysRegenerated`, `debug.turn*` и др.) — работает откат на английский, но стоит дописать переводы (`node tools/validate-languages.js`).

## Архитектурные риски
- **A3.** `id = SHA-256(телефон|почта)` без соли — перебор номеров занимает минуты. Нужен соль/медленный хэш (миграция id затронет всех).
- **A4.** Ящик сервера в памяти: после перезапуска Render недоставленное теряется. Нужен постоянный ящик (Redis/диск) с TTL.
- **A5.** `group-invite` не проверяет, что отправитель — админ; любой участник может переписать состав/название/аватар.
- **A6.** Web Push на iOS ненадёжен; нативная обёртка (см. A4 ниже).
- **A7.** `iceCandidatePoolSize: 2` на каждый PeerLink при сотне контактов даёт десятки allocation на TURN; ограничить пул/создавать по требованию.
- **A8.** Превью ссылок загружает сервер с чужого IP: сделать opt-in на каждое сообщение.

## Криптография и приватность
- **C2.** Подпись каждого сообщения (Ed25519/ECDSA), предупреждение при смене ключа.
- **C3.** Multi-device: корневой ключ личности, устройства подписываются им, зашифрованная синхронизация.
- **C4.** Постквантовый гибрид (X25519 + Kyber768).
- **C5.** Шифрование хранилища на устройстве ключом из PIN (Argon2id), файлы — отдельными ключами.
- **C6.** Sealed Sender: сервер не знает отправителя.
- **C7.** Проверка личности без цифр: QR/руна уже есть; добавить пуш при смене ключа и режим «требовать верификацию перед звонком».

## Сеть и масштаб
- **A1 (сеть).** Группы: замена mesh на sender keys (до сотен участников).
- **A2 (сеть).** SFU для групповых звонков (6 → 32+).
- **A3 (сеть).** Постоянный ящик на сервере.
- **A4 (сеть).** Нативные обёртки iOS/Android для фоновых задач и пушей.
- **A5 (сеть).** Федерация серверов (Matrix/Nostr-подобная модель).
- Звонки на LTE у «Мегафон/МТС/…»: свой TURN на российском VPS (`deploy/setup-coturn.sh`), запасной голосовой канал через сервер, подсказка «включите VPN/Wi-Fi».

## Функционал
- **F1.** Исчезающие сообщения отсчитывать от прочтения, не от отправки.
- **F2.** Правка/удаление/реакции в группах (частично уже есть, проверить полноту).
- **F3.** Настоящие треды вместо «мини-тредов реакций».
- **F4.** Совместное редактирование заметок/списков в чате.
- **F5.** Локальный ИИ (транскрипция голосовых Whisper-tiny, краткое содержание) в WebAssembly.
- **F6.** Голосовая почта.
- **F7.** Видео 1:1 с simulcast.
- **F8.** Локальные «истории» с E2E и истечением.
- **F9.** Постоянные голосовые комнаты.
- **F10.** Синхронизация черновиков между устройствами (после multi-device).

## Аудит V.71.0.0: что не закрыто
- Сервер: регистрация без аутентификации (любой может занять id), оракул скрытого присутствия, TURN-креды выдаются любому.
- Linkauth: привязка DTLS не блокирует контакты, которые ни разу не проходили проверку; конверт v1 без AAD/направления (нужна смена версии).
- Service worker: stale-while-revalidate оставлен как есть; перевод по умолчанию идёт через сторонний сервис.
- Скины — только визуал; названия скинов переведены на en/ru, остальные языки показывают английский.
- Не проверено на устройствах: звуки iOS, распознавание Whisper (загрузка модели и wasm под CSP проверена только до сети), Now Playing. Для проверки есть «Проверка устройства».
- Перед запуском для людей: юрист читает `docs/PRIVACY.md` и `docs/TERMS.md`; подтверждаются лицензии звуков и иконок.
